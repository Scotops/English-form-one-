# English for Secondary Schools - Student's Book Form One

This repository contains the offline-capable Accessible Digital Textbook (ADT)
edition of the Tanzania Institute of Education's *English for Secondary Schools,
Student's Book Form One*.

The reader presents one screen for each of the source PDF's 192 pages (front
matter pages i-vi and printed pages 1-186). Each screen uses a high-quality
facsimile for visual fidelity and includes a structured transcript for screen
readers. Read-aloud follows the printed page with a synchronized
yellow word-by-word highlight; spoken descriptions without a printed text
position use a temporary highlighted current-word caption.

Open `index.html` through a web server. GitHub Pages can serve the repository
directly from its root.
