# English for Secondary Schools - Student's Book Form One

This repository contains the offline-capable Accessible Digital Textbook (ADT)
edition of the Tanzania Institute of Education's *English for Secondary Schools,
Student's Book Form One*.

The reader presents one semantic HTML screen for each of the source PDF's 192
pages (front matter pages i-vi and printed pages 1-186). It uses the book's
extracted illustrations and live text—not full-page screenshots. Read-aloud
follows the content with a synchronized yellow word-by-word highlight and
reviewed image descriptions. Open-ended exercises include a locally saved
response workspace.

Open `index.html` through a web server. GitHub Pages can serve the repository
directly from its root at:

https://scotops.github.io/English-form-one-/
